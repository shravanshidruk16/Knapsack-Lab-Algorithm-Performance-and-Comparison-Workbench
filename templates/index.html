Project Mission & Problem Statement

Course Syllabus Project: 0/1 Knapsack Exact Optimization
DAA Mini-Project

The 0/1 Knapsack Problem is a classic NP-hard combinatorial optimization challenge. Given n items with discrete positive integer weights wi and values vi, and a knapsack with maximum weight capacity W, the goal is to select an optimal subset of items that maximizes cumulative value without exceeding capacity.

Formal Mathematical Model
Maximize:  Z =  ∑ni=1 vi xi
Subject To:   ∑ni=1 wi xi  ≤ W,   where  xi ∈ {0, 1}

Knapsack Lab implements both paradigms in C++17 and evaluates them on identical inputs:

Paradigm 1: Dynamic Programming

Constructs a 2D recurrence table DP[i][w] recording subproblem optima. Operates in pseudo-polynomial time O(n × W) and O(n × W) memory. Uses backtracking through the table to reconstruct exact selected item indices.

Paradigm 2: Branch and Bound

Explores a state-space binary decision tree via Best-First Search with a priority queue (max-heap). Uses continuous fractional relaxation as an admissible upper-bound heuristic to prune unpromising subtrees that cannot surpass the best known feasible solution.

Comprehensive Algorithmic Foundations

1. Dynamic Programming for 0/1 Knapsack

The 0/1 Knapsack problem exhibits optimal substructure: an optimal solution to the subproblem of size i items and capacity w directly incorporates optimal solutions to smaller subproblems.

Recurrence Formulation & Base Case
DP[0, w]  =  0    ∀  w ∈ [0, W]
DP[i, w]  = 
{
DP[i-1, w]      if   wi > w
max(DP[i-1, w],   DP[i-1, w - wi] + vi)      if   wi ≤ w

Solution Reconstruction (Backtracking): Beginning at state (n, W), if DP[i, w] ≠ DP[i-1, w], item i was chosen; we append index i to the solution set, decrement capacity w ← w - wi, and proceed with i ← i - 1.

Pseudo-Polynomial Complexity: Time and space are O(n × W). While polynomial in the integer value W, it is exponential in the input length (bit count L = ⌈log2(W + 1)⌉) of the capacity parameter: O(n × 2L).

2. Branch and Bound State-Space Search

Branch and Bound constructs an implicit binary decision tree where level i represents the decision to include (xi = 1) or exclude (xi = 0) item i.

Fractional Relaxation Upper Bound Heuristic
1. Sorting by Efficiency Ratio: 
v1w1
 ≥ 
v2w2
 ≥ …≥ 
vnwn
2. Upper Bound at Node Level k:
Bound  =  Vcurr  +  ∑m-1j=k vj  +  (W − Wtot) ×
vmwm

Pruning Rule: If Bound(u) ≤ V*best, the entire subtree rooted at node u is immediately pruned without generation. Using a Best-First Search priority queue (max-heap on upper bound), the search continually explores the most optimistic region of the tree first.

3. When Does Branch and Bound Outperform Dynamic Programming?

Branch and Bound significantly outperforms Dynamic Programming in instances where:

  • Large Capacity (W ≥ 10,000): DP requires (n+1)(W+1) table allocations and nested loop iterations, whereas B&B's fractional relaxation bound prunes the decision tree after examining only a handful of nodes (often executing in under 0.05 ms).
  • High Ratio Variance: When item value-to-weight ratios differ substantially, the fractional upper bound is sharp, enabling early and aggressive tree pruning.
  • Conversely: When W is small and item ratios are nearly identical, DP wins decisively due to constant-time table lookups, CPU cache locality, and lack of priority queue heap operations.
